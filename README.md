# Nada — A little message

Arabic, dark-cinematic, step-by-step confession page.

## Run
Extract the ZIP and open `index.html` in a browser. No build tools or backend needed.

## Customize
Edit the text in `index.html`, styles in `style.css`, and navigation in `script.js`.

## Publish
Upload the three web files to a GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from branch → main / root.

The page does not collect or transmit responses.
